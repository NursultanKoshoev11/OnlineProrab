Коротко: STROY обрабатывает данные, необходимые для входа по номеру телефона, работы объектов, расходов, файлов, команды и поддержки.

1. Общие положения

Политика описывает обработку данных сервисом STROY и мобильным приложением STROY. Сервис доступен через приложение и сайт stroy.com.kg.

Оператором для целей этой Политики является владелец и разработчик проекта STROY. Контакт по вопросам данных: nursultankosoev2@gmail.com.

2. Какие данные обрабатываются

  • Аккаунт: номер телефона, идентификатор, сессии и данные профиля, если вы их добавляете.
  • Объекты: название, адрес или описание, дата начала, статус и введённые вами сведения.
  • Расходы и отчёты: название, сумма, валюта, дата, описание, поставщик и связанные записи.
  • Файлы: фотографии, чеки и обложки проектов, прикреплённые пользователем.
  • Команда: номера телефонов приглашённых участников, роли и связь с объектом.
  • Безопасность: время запросов, события входа, данные для ограничения злоупотреблений и технические журналы.
  • Голосовой поиск и поиск расходов с AI: аудио для распознавания речи, текст запроса и сведения о расходах, которые нужны для выбранной функции.

В текущей версии приложение не запрашивает геолокацию устройства. Адрес объекта вводится пользователем. Микрофон может использоваться только для включённого голосового ввода.

3. Цели обработки

  • создание и защита аккаунта, отправка SMS-кода и поддержка сессии;
  • работа объектов, расходов, отчётов, прикреплённых файлов и командных прав;
  • синхронизация, поиск, поддержка и исправление ошибок;
  • безопасность и предотвращение злоупотреблений.

Мы не продаём персональные данные и не используем содержимое проектов для рекламных рассылок.

4. Передача данных

Данные могут обрабатываться техническими поставщиками, необходимыми для работы STROY: инфраструктурой размещения, SMS-провайдером и подключёнными каналами поддержки. Передаётся только необходимый объём данных.

При голосовом поиске аудио обрабатывает системный сервис распознавания речи устройства. На iOS сервис Apple может отправлять аудио на серверы Apple для распознавания; на Android обработку выполняет системный сервис, выбранный на устройстве. STROY не отправляет исходную аудиозапись на свой сервер. Распознанный запрос передаётся серверу STROY, только когда вы нажимаете «Найти расходы».

Если на сервере включён AI-поиск расходов, сервер передаёт запрос и сведения о расходах выбранного объекта (идентификаторы записей, названия, описания, категории, суммы, валюты, поставщиков и даты) настроенному AI-провайдеру. В зависимости от конфигурации это могут быть Google Gemini, Groq или OpenRouter. Эти поставщики обрабатывают переданные сведения по собственным условиям и политике конфиденциальности. Не вводите в голосовой или AI-запрос пароли, коды и другие чувствительные данные.

Данные проекта видны другим участникам этого проекта в пределах назначенной роли. Раскрытие также возможно, если этого требует закон или это нужно для защиты сервиса.

5. Хранение и безопасность

Данные хранятся столько, сколько нужно для аккаунта, проекта, безопасности, обработки запросов и законных обязанностей. Срок зависит от типа данных.

Для ограничения попыток SMS-входа сервер сохраняет нормализованный номер телефона, IP-адрес клиента, тип и время попытки, а также её результат. Эти записи обычно хранятся 7 дней. Записи SMS-кодов, включая номер телефона и хэш кода, хранятся 24 часа после истечения срока действия кода. Плановая очистка запускается примерно каждые 6 часов и удаляет записи партиями. При большом объёме очереди или временной недоступности базы фактическое удаление может задержаться.

Технические журналы API передаются в AWS CloudWatch Logs в выбранном регионе AWS. Обычная запись запроса содержит идентификатор запроса, метод, шаблон маршрута без значений параметров, HTTP-статус, размер ответа и длительность обработки. Отдельные записи об ошибках могут содержать внутренние идентификаторы аккаунта, проекта или файла, а также технические сведения об ошибке. Журнал запросов не содержит тела запроса, query-параметров или IP-адреса клиента. По умолчанию журналы хранятся 30 дней, затем удаляются; фактический срок может быть изменён настройкой окружения.

Используются HTTPS, контроль доступа, токены авторизации и ограничения попыток входа. Абсолютная безопасность передачи данных через интернет не гарантируется.

После удаления аккаунта мы бессрочно храним в закрытом журнале минимальную запись для защиты от восстановления данных из старых или отключённых резервных копий: идентификатор удалённого аккаунта либо путь удалённого файла и время удаления. Журнал не содержит имя, номер телефона или содержимое профиля. Эти записи используются только для того, чтобы резервное копирование не вернуло удалённые данные.

Для защиты аккаунта мы можем попросить подтвердить владение номером телефона. Не отправляйте пароль, SMS-код или токен доступа.
