# Design decisions

STROY is a working tool for construction projects. The interface should make project names, costs and actions easy to scan.

- Warm off-white backgrounds, white working surfaces and a restrained forest-green accent.
- Native Android typography with fewer heavy weights, clearer heading hierarchy and more readable metadata.
- Project cards prioritize names and locations. Real cover photos remain supported; projects without photos no longer repeat decorative house thumbnails.
- Expense totals receive a distinct, legible summary. Supporting dates and section links have lower visual emphasis.
- Status indicators use compact labels. Buttons have restrained corner radii and native pressed/focus feedback.
- Login, forms, reports and team screens share the visual hierarchy. Existing Russian content and project workflows are retained.

No new UI package was added. Existing Flutter/Material controls and API repositories remain in use.
