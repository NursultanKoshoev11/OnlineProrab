# OnlinePRorab mobile redesign

The active Flutter UI follows the approved construction-object-first design reference in `docs/design/onlineprorab-ui-reference.svg`.

Primary flow:
- Objects list
- Object overview
- Expenses and search
- Tasks
- Team, reports, files, and expense analytics

The microphone search surface is present in the expenses UI. Native speech-to-text and semantic AI query processing are intentionally separate integration work and are not represented here as completed.
